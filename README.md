# 🛡️ DarknessTool 1.1

🇷🇺 **Русская версия** · 🇬🇧 [English version](README_ENG.md)

## ✨ Возможности

| Модуль | Что делает |
|---|---|
| 🧩 **Диспетчер задач** | Процессы (CPU, RAM, диск, сеть), подпись, VT-вердикт, дерево, завершение, заморозка, свойства, модули, потоки, дескрипторы |
| 🗝 **Редактор реестра** | Дерево, правка всех типов значений, поиск, бэкап ветки, откат, работа с оффлайн-кустами |
| 🗂 **Оффлайн-доступы** | Службы, драйверы, планировщик, профили пользователей — в незагруженной Windows |
| 🔍 **Сканер закрепа** | IFEO, Winlogon, AppInit_DLLs, Run/RunOnce, Startup, задачи, службы, драйверы, WMI-подписки, политики, BHO |
| 🔓 **Мастер блокировок** | Снятие блокировок диспетчера, реестра, cmd, USB, Autorun, .exe/.reg, hosts и др. |
| 📊 **Сравнение реестра** | Снимок «до/после», diff, откат изменений |
| 🔤 **Шрифты системы** | Сброс шрифтов и ассоциаций к заводским |
| 🔑 **Замена Utilman.exe** | Доступ к заблокированной системе (с бэкапом) |
| 🗄 **Карантин** | Все удаления — в карантин с возможностью восстановления |
| 🧪 **Скрипты PowerShell** | Свои правила лечения с логированием и откатом |
| 🔗 **VirusTotal** | Проверка хэшей файлов из автозагрузки и процессов (опционально) |
| ✍️ **Проверка подписи** | Статус подписи для всех файлов, фильтр «только неподписанные» |
| 📖 **Справка** | Встроенный справочник, работает в WinRE |

## 🚀 Почему DarknessTool

- ✅ Работает в **WinRE** — лечение мёртвой системы с флешки
- ✅ **Оффлайн-режим** — службы, драйверы, задачи, профили
- ✅ **Откат любого действия** — карантин + журнал изменений
- ✅ **Один `.exe`** — без установки, без зависимостей
- ✅ **Портативность** — ничего не оставляет на заражённой машине
- ✅ **Open Source** — MIT

## 🎯 Сценарии

**Чистка живой системы** → Диспетчер → Автозагрузка → Сканер закрепа → Карантин

**Лечение с флешки** → WinRE → Оффлайн-доступы → Службы/драйверы → Перезагрузка

**Восстановление доступа** → WinRE → Мастер блокировок / Замена Utilman

**Анализ изменений** → Снимок реестра → Diff → Откат
